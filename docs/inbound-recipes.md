# Встроенные и плагинные рецепты подключений

Мастер подключений (`/inbounds`) предлагает готовые рецепты. Рецепт подставляет протокол,
порт, транспорт, безопасность, flow, путь и безопасные настройки. Для Reality-рецептов
ключи X25519, shortId, SNI и `realityDest` генерируются автоматически на бэкенде.

## API

- `GET /api/inbounds/recipes` — список рецептов (built-in + плагины).
- `POST /api/inbounds/recipes/:id/prepare` — вернуть готовый `CreateInboundDto` с ключами.
  Тело: `{ "nodeId": "<uuid>", "tag": "My node" }`.

## Мастер подключения

В форме подключения сначала выбирается нода, затем рецепт. Рецепты разделены на группы:
«Для клиентов» (основной Reality), «Запасные и плагины» и «Для проверки» (без маскировки —
только для диагностики). Названия рецептов на русском языке. При смене ноды рецепт
пересчитывает SNI и порт. Если на ноде уже есть подключения, форма предлагает привязать
пользователей к существующему подключению вместо создания нового.

Расширенные поля (транспорт, ключи, лимиты, fallback, JSON) свёрнуты: рецепт заполняет их
автоматически. После создания подключения панель применяет конфигурацию ноды, предлагает
привязать пользователей (всех или одного) и показывает QR со ссылкой на подписку.

## Выбор порта

`prepare` с `nodeId` проверяет порты ноды (подключения и шаги цепочек). Если порт рецепта занят,
выбирается первый свободный из опубликованных портов агента: 443, 2054, 4436, 2053, 5050–5060, 10000–10010.
Ответ содержит `autoPort`, `recipePort` и `portBusyBy`. Создание или изменение подключения
на занятом порту той же ноды отклоняется с ошибкой 400. Reality-рецепты требуют `nodeId`,
а тег получает суффикс `-2`, `-3`, если такой уже есть.

## Встроенные рецепты

| id | Описание |
|---|---|
| `vless-reality-selfsni` | VLESS Reality на 443, `xtls-rprx-vision`, маскировка под домен ноды и локальный decoy `127.0.0.1:8443` |
| `vless-reality-alt` | Аналогично, порт 2054 |
| `vless-reality-4436` | Аналогично, порт 4436 (нужен проброс порта на ноде) |
| `vless-plain` | VLESS без TLS на 2053 |
| `vmess-ws` | VMess over WebSocket, `/ws`, порт 2053 |

## Рецепты от плагинов

Плагин может зарегистрировать рецепт через SDK:

```js
sdk.recipes.register({
  id: 'my-provider-reality',
  name: 'My Reality',
  description: 'Generated by my plugin',
  protocol: 'vless',
  transport: 'tcp',
  security: 'reality',
  port: 4443,
  flow: 'xtls-rprx-vision',
  generateKeys: true,
});
```

и удалить его:

```js
sdk.recipes.unregister('my-provider-reality');
```

Рецепты хранятся в таблице `PluginRecipe` и появляются в общем списке. При удалении плагина
его рецепты удаляются. Плагин не может перезаписать встроенный рецепт: ID должен быть уникальным
в рамках `pluginId`.

## Проверка

После применения рецепта и создания подключения вызвать `POST /api/nodes/:id/apply` и проверить:

```bash
docker exec xss-agent-1 xray run -test -c /etc/xray/config.json
```
