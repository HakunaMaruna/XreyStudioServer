# Публичная страница подписки

Публичная страница открывается по ссылке `/sub/<token>` и управляется из раздела
**Оповещения / выставление → Страница подписок** (`/subscription-page`).

## Что изменилось

- Адаптивный mobile-first интерфейс, светлая/тёмная тема с автоопределением и переключателем.
- Переключатель языка RU/EN.
- Карточка подписки: статус, оставшийся трафик с прогресс-баром, срок и обратный отсчёт.
- QR и копирование ссылки.
- Раздел «Приложения для VPN»: определение ОС по User-Agent, вкладки платформ,
  one-click deep link, ссылки на скачивание и короткие инструкции.
- Состояния: загрузка, ошибка, истекла, отключена, лимит трафика, лимит устройств.
- Предпросмотр в панели через iframe `/sub/preview`.

Старая логика выдачи подписок не тронута: `/api/subscriptions/<token>?format=...`,
детект по User-Agent, HWID-binding и заголовки `Cache-Control/Referrer-Policy` работают как прежде.
В JSON-ответ добавлены поля `page` (настройки) и `page.apps`.

## Настройки

Глобальные настройки хранятся в `SubscriptionPageSettings` (singleton `default`):
бренд, заголовок, описание, логотип/favicon, акцент, фон, тема по умолчанию, свой CSS,
блоки (QR/трафик/срок/приложения/инструкции/поддержка), ссылки поддержки, объявление, язык.

Шаблон подписки (`SubscriptionTemplate.pageSettings`) может переопределить любые из этих
полей для пользователей, привязанных к шаблону.

Приложения хранятся в `VpnApp`: имя, платформа, иконка, ссылка на скачивание, deep link,
инструкции RU/EN, порядок, включено. Список редактируется в разделе «Приложения».

## Deep links

Шаблон обязан содержать `{subscription_url}`. Панель подставляет URL через
`encodeURIComponent`. Поддерживаются кастомные схемы (`happ://`, `v2rayng://`, `clash://`, …).
`javascript:` и `data:` запрещены. Если у приложения нет проверенной схемы — deep link
оставляется пустым, пользователь копирует ссылку вручную.

Дефолтные ссылки на скачивание проверены HTTP-запросами 2026-11-25: GitHub/App Store — 200,
Happ — 403 для HEAD (сайт доступен в браузере), Streisand — перенесён на GitHub.
Схемы deep link подтвердить программно невозможно; при расхождении редактируйте шаблон в панели.

## Безопасность

- Пользовательские строки рендерятся React как текст; `dangerouslySetInnerHTML` не используется.
- Свой CSS санитизируется: удаляются теги, `@import`, `url()`, `expression`, `javascript:`.
- URL логотипа/favicon/поддержки/приложений проходят проверку схемы http/https/mailto.
- Настройки и приложения доступны ADMIN на запись, OPERATOR — на чтение.

## API

```text
GET/PATCH /api/subscription-page/settings
GET/POST /api/subscription-page/apps
PATCH/DELETE /api/subscription-page/apps/:id
GET /api/subscriptions/preview
```
